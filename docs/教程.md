# lx-music 云同步图文教程

## 准备工作

- 已下载桌面版 lx-music（解压 lx-music-desktop.zip）
- 已下载手机版 lx-music-android.apk
- 一个邮箱账号（用于注册 Supabase）

---

## 第一步：注册 Supabase

1. 打开 https://supabase.com
2. 点击 **Start your project**
3. 选择 **Sign up with Google**（或其他登录方式）
4. 登录后进入 Dashboard

---

## 第二步：创建新项目

1. 点击 **New project**
2. 填写信息：
   - **Organization**：选择默认或创建一个
   - **Name**：输入 `lx-music`（随便取，自己记得就行）
   - **Database Password**：自动生成或自定义
   - **Region**：选近的（如 Singapore）
3. 点击 **Create new project**
4. 等待约 2 分钟（项目初始化需要时间）

---

## 第三步：运行建表 SQL

1. 左侧菜单点击 **SQL Editor**（图标 `</>`）
2. 空白编辑器会显示
3. 从 GitHub 仓库下载 `supabase_setup.sql` 文件
4. 复制全部内容到编辑器
5. 点击右上角 **Run** 按钮
6. 弹出警告框 **"Potential issue detected"** → 点击 **Run query**（黄色按钮）
7. 看到 **Success. No rows returned** 即表示成功

> ✅ 此时数据库已创建 5 张表：
> - lx_sync_devices（设备表）
> - lx_sync_snapshots（快照表）
> - lx_sync_actions（动作表）
> - lx_sync_cursors（游标表）
> - lx_sync_meta（密钥表）

---

## 第四步：获取连接信息

1. 左上角点击项目名旁边的 **Project Settings**（齿轮图标）
2. 在页面顶部找到 **Project URL** 和 **Publishable key**
3. 分别点击右侧 **Copy** 按钮复制

![获取 API 密钥](https://i.imgur.com/xxx.png)
> *提示：如果看不到截图，请参照下方文字说明*

**需要复制的值：**
- **Project URL**：格式为 `https://xxxx.supabase.co`
- **Publishable key**：格式为 `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`

---

## 第五步：配置桌面版

1. 打开 lx-music 桌面版
2. 点击右上角 **设置**（齿轮图标）
3. 左侧找到 **数据同步**
4. 填写：
   - **Supabase URL**：粘贴 Project URL
   - **Anon Key**：粘贴 Publishable key
   - **Sync Secret**：保持默认 `YOUR_SYNC_SECRET_HERE`
5. 点击 **保存**
6. 点击 **测试连接**，看到 **"已连接"** 即可

---

## 第六步：配置手机版

1. 打开 lx-music 手机版
2. 点击底部 **设置**
3. 找到 **数据同步**
4. 填写与桌面版相同的三项信息
5. 点击保存

---

## 第七步：开始同步

1. 在桌面版/手机版中浏览歌曲
2. 添加歌曲到歌单或 dislike
3. 点击 **同步** 按钮
4. 切换到另一台设备
5. 点击 **同步** 即可看到数据同步过来

---

## 常见问题

**Q: 同步失败怎么办？**
A: 检查 URL 和 Key 是否正确，确认 SQL 已运行成功。

**Q: 多人使用同一个项目？**
A: 可以，但建议各自创建独立项目，避免数据混乱。

**Q: 如何修改 Sync Secret？**
A: 在 Supabase SQL Editor 执行：
```sql
update public.lx_sync_meta set value = '新密钥' where key = 'sync_secret';
```
然后所有设备更新 Sync Secret 配置。

**Q: 免费版够吗？**
A: 个人使用足够（500MB 数据库 + 1GB 存储）。
